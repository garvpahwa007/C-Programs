# Terminal Snake

A small, easy-to-play Snake game written in C.

```sh
make
./snake
```

Use arrow keys or `W`, `A`, `S`, `D` to move. Eat `@`, avoid your tail, walls,
and `#` barriers. Every 50 points adds a barrier and speeds the game up.

- `p` pauses/unpauses
- `r` restarts after a game over
- `q` quits
